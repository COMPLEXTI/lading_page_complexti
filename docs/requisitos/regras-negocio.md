# Regras de negócio — #2

## RN-001 — Endereço institucional único

O e-mail exibido no rodapé deve ser **desenvolvimento@complexti.com.br**, o mesmo utilizado na seção Contato, no JSON-LD (`index.html`) e na Política de Privacidade.

## RN-002 — Link acionável

O e-mail no rodapé deve ser um hyperlink com esquema `mailto:desenvolvimento@complexti.com.br`.

## RN-003 — Consistência visual

O link do e-mail no rodapé deve seguir o mesmo padrão tipográfico e de hover dos demais links do rodapé (texto `text-sm`, cor `slate-500`, hover `green-400`).
